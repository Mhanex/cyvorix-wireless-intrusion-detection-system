# CWIDS - Cyvorix Wireless Intrusion Detection System

CWIDS is a passive Wireless Intrusion Detection System developed by
Cyvorix Technologies for monitoring authorised wireless environments.

The system captures and analyses selected IEEE 802.11 management-frame
activity, detects abnormal deauthentication and disassociation behaviour,
records security events and alerts, and provides administrators and
security analysts with a browser-based monitoring and investigation
platform.

CWIDS is intended for defensive cybersecurity monitoring, authorised
security testing, security laboratories and organisational wireless
security operations.

## Version

Current release: CWIDS v1.0.2

## Key Features

- Passive wireless monitoring
- Monitor-mode adapter detection
- Authorised AP selection
- SSID, BSSID and channel scoping
- Deauthentication detection
- Disassociation detection
- Threshold and correlation-based alerting
- Alert severity classification
- Real-time dashboard
- Live Monitor
- Alert investigation
- Monitoring sessions
- Security log search and filtering
- CSV and JSON export
- Role-Based Access Control
- Administrator, Security Analyst and Viewer roles
- HTTPS web management
- Gunicorn and Nginx production serving
- systemd-managed sensor and web services
- Automatic startup
- SHA-256 verified organisation deployment packages
